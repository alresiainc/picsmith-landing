Privacy Policy

Last updated: August 2026

Short version: Picsmith runs entirely inside your browser. Your designs are stored on your own device and are never uploaded to us — we don't operate any server that receives them. Three things can cause a network request, and you trigger every one of them yourself: running a cloud AI tool (sends that specific image or prompt to OpenAI, with your own key); downloading the on-device background-removal engine (a one-time ~15MB fetch you explicitly approve first); and switching on update checking (off by default, fetches only a version number).

What Picsmith stores, and where

  • Your design projects (layers, images, text, shapes) are saved locally in your browser's IndexedDB storage. They stay on your device.
  • Your settings (preferences, your own OpenAI API key if you add one, your Picsmith Pro license key if you have one) are saved locally via the browser's extension storage.
  • None of the above is transmitted to any server we operate. We don't run a backend, and we don't have accounts or sign-in — there's nothing tied to your identity for us to collect.

Cloud AI is opt-in and bring-your-own-key

Picsmith's AI tab (prompt-based edits, style transfer, text-to-image, analysis) is optional and free — add your own OpenAI API key in Settings and it unlocks, no Picsmith Pro required. When you run one of these tools:

  • The image and/or prompt text for that specific action is sent directly from your browser to OpenAI's API (api.openai.com), authenticated with your own API key.
  • We never see, receive, or store that data — the request doesn't pass through any server of ours.
  • That data is then subject to OpenAI's own privacy policy, since they're the ones processing it.

On-device background removal downloads a small engine once, with consent

Image ▸ Remove background (AI) is a separate, Pro-only feature that runs a neural network (U²-Net) entirely on your device — it never sends your image anywhere. The engine itself, however, is not bundled in the extension install (that would make every install larger, for a tool most people never touch):

  • The first time you use it, Picsmith shows a dialog stating the size (~15MB) and that it's a one-time download — nothing fetches until you click through it.
  • That download pulls two files — the ONNX Runtime engine and the model weights — from picsmith.alresia.tech/ai-assets/. They are stored in your browser's own Cache Storage.
  • Every use after that is served from that local cache — no further network activity, and the actual image processing never leaves your device, then or ever.
  • This feature requires an active Picsmith Pro license, since hosting that download costs us bandwidth regardless of who's asking.

Update checking is off until you turn it on

Out of the box, Picsmith makes no network requests at all. If you enable Settings → Updates → Check for new versions, then at most once a day it fetches a single small file — picsmith.alresia.tech/version.json — which contains nothing but the latest version number.

  • The request sends no information about you, your designs, or how you use the app. It's an ordinary web request, so our host sees what any web server sees: an IP address and a timestamp.
  • We don't log, profile or retain those requests for analytics, and there's no identifier attached that could link one check to another.
  • Picsmith never installs anything by itself. If a newer version exists it tells you, and you decide whether to download it.
  • Switching the setting back off stops the checks immediately.

What we don't do

  • No analytics, telemetry, or usage tracking.
  • No advertising or ad networks.
  • No selling, renting, or sharing of data — we don't have any of your data to share in the first place.
  • No account, sign-up, or personal information required to use the free tier.

Picsmith Pro licensing

A Pro license key is a short signed code; validating it happens entirely on your device and doesn't contact any server. We don't collect payment or personal information as part of license validation.

Changes to this policy

If this policy changes, we'll update the date at the top of this page and, for material changes, note it in the extension's release notes.
