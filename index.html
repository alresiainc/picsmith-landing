Privacy

Your images never
leave the machine.

There is no Picsmith server. Nothing to sign up for, nothing to leak — your designs live in your browser's own storage and are never uploaded. The one exception is the optional AI tier, which talks straight to OpenAI using a key you provide yourself.

Get Picsmith

Install it in
under a minute.

Picsmith isn't on the extension stores yet — the listings are in progress. Until then, download the source and load it unpacked. It's the same build, and it updates the moment you drop in a new one.

Download the extension
Coming to the Chrome Web Store and Microsoft Edge Add-ons. Want a nudge when it lands? Watch the project on GitHub.
  1. Unzip the download somewhere you'll keep it.
  2. Open chrome://extensions — or edge://extensions.
  3. Turn on Developer mode (top-right).
  4. Click Load unpacked and pick the unzipped folder.
  5. Pin it to the toolbar and open a new design.
